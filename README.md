# 🌱 우리집 성장 기록

아이의 **말·생각·탐구 과정·작품·관심사·공식서류**를 가족이 함께 쌓는 비공개 웹앱입니다.
사진 한 장, 말 한 줄이면 저장되고 — 태그만 붙여 두면 나중에 주제별·시기별로 저절로 모입니다.

- 앱 주소: `https://elleyoonna-cmd.github.io/growth-archive/`
- 휴대폰·PC 모두 사용 가능 (설치 없이 브라우저에서, 홈 화면에 추가하면 앱처럼)
- 검색엔진에는 노출되지 않습니다(`noindex, nofollow`)
- **독서기록장(Reading Garden)과는 별개의 앱입니다.** 메뉴·데이터가 섞이지 않습니다.

## 무엇을 남길 수 있나요?

| 탭 | 하는 일 |
|---|---|
| **🏠 홈** | `＋ 지금 남기기`로 1분 기록. 사진·파일·목소리, 아이 말, 부모 메모, 날짜, 유형·주제 태그, 혼자/도움 토글. 기록 카드를 눌러 **이어쓰기**로 다음 시도·달라진 생각을 쌓을 수 있어요. |
| **🗺️ 모아보기** | 주제 태그별 자동 모아보기(시기별 변화·관련 기록), 월·학기·연도별 돌아보기, 기간·주제를 골라 **모음집(PDF·인쇄)** 만들기 |
| **📁 서류함** | 생활기록부·성적·수료증·기관 피드백 등 공식서류를 일상 기록과 **분리**해 원본 그대로 보관. 상태(보유중/재발급필요/완료), 실물 보관 위치, PIN 잠금 |
| **⚙️ 설정** | 아이 이름·생년월일, 가족 방 코드, 서류함 PIN, **전체 내보내기(ZIP)·복원**, 전체 지우기 |

### 1분 기록, 이렇게 씁니다

1. 홈에서 **＋ 지금 남기기**
2. 사진을 고르거나(자동으로 가볍게 줄여요) 목소리를 녹음합니다 — 녹음은 **버튼을 누를 때만** 시작해요
3. 아이가 한 말을 **그대로** 한 줄 적습니다. 엄마·아빠의 생각은 **부모 메모**에 따로 적어요
4. `#로봇` `#수학` 같은 주제 태그와 유형(`#생각` `#질문·탐구` `#작품` `#협업`)을 고릅니다
5. 저장 — 제목을 비우면 `11월 15일 · 질문·탐구`처럼 자동으로 붙어요

> 길게 쓰지 않아도 괜찮습니다. 나중에 필요할 때 이어쓰기와 태그로 과정을 연결하면 됩니다.

### 이어쓰기

기록 카드에서 **＋ 이어쓰기**를 누르고 사진이나 한 줄만 붙이면, `질문 → 시도1 → 실패 → 수정 → 완성` 과정이 카드 안에 타임라인처럼 쌓입니다. `나란히 비교`로 버전을 옆으로 놓고 볼 수 있어요.

### 모음집(PDF·인쇄)

`모아보기 → 모음집` 또는 홈의 `📄 모음집 만들기`에서 기간·주제를 고르고 사진·아이 원문·부모 메모를 체크한 뒤 미리보기 → **인쇄 / PDF 저장**. 출력물에는 “가족 작성 자료”라고 표시됩니다.

## 가족과 함께 쓰기 (실시간 공유)

1. `⚙️ 설정 → 👨‍👩‍👧 가족 방`
2. **코드 자동 만들기**를 누르거나 직접 코드를 정합니다(예: `growth-family-x7k2m9`)
3. 가족 폰·PC에서 같은 앱을 열고 같은 코드를 넣으면, 한쪽에서 남긴 기록이 **새로고침 없이** 다른 쪽에 나타납니다

- 코드를 정하지 않으면 이 기기에만 저장됩니다.
- 방 코드를 아는 기기만 함께 볼 수 있어요. 가족에게만 알려 주세요.
- 사진은 800px로 줄여 올라가고, 설정에서 가족 방 데이터 크기(권장 4.2MB)를 볼 수 있습니다.
- 기록이 없는 새 기기가 방을 열어도 **기존 기록을 지우지 않습니다**(자동 보호).

## 백업과 복원

- `⚙️ 설정 → 💾 보관·백업 → ⬇ 전체 내보내기(ZIP)`
  - 사진·음성·서류 **원본 파일** + `data.json` + `records.csv`/`documents.csv` + 앱 없이 읽는 `archive.html` + 복원 안내 `README.md`
  - 외부 링크가 아니라 이 기기에서 바로 만들어 내려받습니다
- `⬆ 복원 (JSON/ZIP)` — 파일을 고르면 **새 기록·중복 기록 수를 먼저 보여 주고**, `새 항목만 병합` 또는 `전체 덮어쓰기`를 고를 수 있습니다.
- ZIP에는 아이 사진·음성·서류가 들어 있으니 공개 링크·공개 저장소에 올리지 마세요.

## 개인정보

- 아이 이름·생년월일은 **기기와 가족 방 안에만** 저장되고 앱 코드에는 들어가지 않습니다.
- 서류함 PIN은 화면 잠금입니다(파일 암호화 아님). 기기를 가족이 함께 쓰는 경우를 위한 잠금이에요.
- 평가·점수·다른 아이와의 비교·연속 작성 일수 같은 기능은 넣지 않았습니다.
